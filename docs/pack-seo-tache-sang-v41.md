## Angle éditorial

La page évite les recettes virales cumulant bicarbonate, vinaigre, sel, eau oxygénée et
percarbonate. Elle suit une hiérarchie :

1. retirer à l’eau ce qui peut l’être ;
2. traiter la composante protéique avec un produit formulé ;
3. laver ;
4. traiter éventuellement la coloration résiduelle avec un agent oxygéné compatible ;
5. contrôler avant tout sèche-linge ou repassage.
