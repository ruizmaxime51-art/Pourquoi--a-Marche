# Liens Amazon à fournir pour le lot de 50 recettes

Les 50 recettes utilisent déjà tes produits existants (balance, thermomètre, bocaux, pH-mètre,
gants, lunettes, acide citrique, cristaux de soude, percarbonate, flacons…).
Voici les produits **sans lien** qui reviennent dans les fiches, classés par priorité.
Pour chacun, envoie-moi le lien Amazon avec ton tag : je crée la clé dans `lib/affiliations.js`
et je l'ajoute aux fiches concernées.

## À ne pas mettre en lien
Casseroles, saladiers, spatules ordinaires, couteaux, bouilloire, minuteur : trop génériques, peu de
commission et ils encombrent la fiche.
